# Antenne 📡

Déploie une web radio en quelques minutes.

**Antenne** est un outil pour lancer rapidement une radio en ligne, avec :

- 🎙️ **Prise d'antenne en direct** — une interface pour prendre le micro et parler en live.
- 🎵 **Diffusion 24/7** — laisse tourner tes sons en continu à partir de fichiers musicaux uploadés.
- 🚀 **Déploiement rapide** — de zéro à une radio en ligne en un minimum d'étapes.

## Statut

🚧 En cours de développement.

## Concept

Une radio, c'est deux choses : de la musique qui tourne tout le temps, et une voix qui prend l'antenne quand elle le veut. Antenne réunit les deux dans une interface simple :

1. Upload tes fichiers audio → ils tournent en boucle / en playlist 24/7.
2. Un clic sur « Prendre le micro » → tu passes en direct par-dessus la musique.
3. Partage l'URL → tes auditeurs écoutent le flux.
